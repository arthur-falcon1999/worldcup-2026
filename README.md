# 🏆 FIFA World Cup 2026 — Schedule

A single-page schedule for the 2026 FIFA World Cup (USA · Canada · Mexico), with all kickoff times shown in **Mountain Time**, team search/filtering, a countdown to the opening match, and links to each team's official FIFA.com page.
